# Safety and Responsibility / 安全边界和责任说明

## 中文

NZ Visa Auto Push 是表单准备辅助工具，不是政府服务，也不保证申请成功。

### 必须人工完成的步骤

用户必须手动完成：

- CAPTCHA
- 多因素验证或安全检查
- 最终政府提交
- 付款
- 所有信息的最终核对

### 信息准确性

申请人必须确保所有填写内容真实、准确，并且和本人证件及实际情况一致。工具只会按照配置文件填写内容，不判断法律资格，也不替用户承担申请责任。

### 账号安全

建议一个申请人只使用一个 INZ 账号和一个浏览器会话。不要多人共用同一个账号同时运行，也不要对同一个账号开启多个竞争会话。

### 授权安全

私有授权包可以锁定姓名和出生日期，减少授权包被随意转给其他人使用的风险。

离线授权不能做到绝对不可破解。如果需要“一个 key 全网只能激活一次”，需要额外的在线激活服务器记录授权状态。

### 使用建议

- 正式申请前先完整跑一遍测试流程。
- 保持电脑网络稳定。
- 提前确认 INZ 账号密码能正常登录。
- 提前确认 `config/applicant.json` 内的信息已经按本人情况更新。
- 最终提交前逐项检查页面内容。

## English

NZ Visa Auto Push is a form-preparation assistant. It is not a government service and does not guarantee application success.

### Human-Controlled Steps

The user must manually complete:

- CAPTCHA
- multi-factor or security checks
- final government submission
- payment
- final review of all information

### Data Accuracy

Applicants must ensure all answers are truthful, accurate, and consistent with their documents and real situation. The tool only fills configured values. It does not determine legal eligibility or take responsibility for the application.

### Account Safety

One applicant should use one INZ account and one browser session. Do not share one account across multiple people at the same time, and do not run multiple competing sessions for the same account.

### License Safety

Private licensed packages can lock name and date of birth to reduce casual reuse by another person.

Offline licensing cannot be absolutely unbreakable. A true "one key can activate only once globally" model requires an online activation server.

### Recommendations

- Run the full rehearsal flow before the real application.
- Keep the network stable.
- Confirm the INZ account can log in before the opening time.
- Confirm `config/applicant.json` matches the applicant's real situation.
- Review every page before final submission.
