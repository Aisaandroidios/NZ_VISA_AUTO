# Safety and Responsibility

NZ Visa Auto Push is a form-preparation assistant. It is not a government service and does not guarantee application success.

## Human-Controlled Steps

The user must manually complete:

- CAPTCHA
- identity/security checks
- final government submission
- payment
- final review of all information

## Data Accuracy

Applicants must ensure all answers are truthful and match their documents. The tool fills configured values only; it does not verify legal eligibility.

## Account Safety

Use one browser session per applicant. Do not run multiple competing sessions for the same INZ account.

## License Safety

Licensed builds may lock name and date of birth so a package issued for one person cannot be casually reused for another person.
